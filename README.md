# AI Quota Sharing

**Sharing is caring. What if AI quota worked that way?**

An opt-in product proposal for ChatGPT/Codex, Claude/Claude Code, and Mistral’s Le Chat. Lend a chosen share of unused eligible allowance, borrow within a cap when you hit your limit, and contribute back what you borrow before borrowing again the following month.

Each provider would manage its own pool. This community proposal requires provider-side support; the mockup illustrates proposed functionality.
